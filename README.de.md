# AI Prompt Manager

**KI-Prompts lokal speichern, mit Ordnern & Variablen verwalten und mit einem Klick kopieren.**

![Plattform](https://shields.io)
![Lizenz](https://shields.io)
![App-Sprache](https://shields.io)

## ✨ Funktionen

* **Lokale Speicherung:** Speichere deine wichtigsten KI-Prompts direkt und datenschutzfreundlich auf deinem Gerät – jederzeit offline verfügbar.
* **Ordner-Struktur:** Behalte den Überblick und sortiere deine Prompts übersichtlich in eigenen Ordnern.
* **Dynamische Variablen:** Nutze Platzhalter bzw. Variablen in deinen Vorlagen, die du vor dem Kopieren flexibel ausfüllen kannst.
* **Schnelles Kopieren:** Kopiere fertige Prompts mit einem Tipp in die Zwischenablage für ChatGPT, Gemini, Claude und andere KI-Tools.
* **Zweisprachig:** Die Benutzeroberfläche unterstützt Deutsch und Englisch.

## 📥 Download & Installation

### Option 1: Automatische Updates über Obtainium (Empfohlen)
Du kannst **AI Prompt Manager** über [Obtainium](https://github.com) installieren und erhältst automatisch Benachrichtigungen, sobald ein neues Release auf GitHub erscheint:

[<img src="https://githubusercontent.com" alt="Get it on Obtainium" height="55">](https://imranr.dev)

### Option 2: Manueller APK-Download
1. Öffne die Seite [GitHub Releases](https://github.com/synapseki/AI-Prompt-Manager).
2. Lade dort unter **Assets** die aktuelle `.apk`-Datei herunter.
3. Öffne die Datei auf deinem Android-Gerät und erlaube bei Bedarf die Installation aus unbekannten Quellen.
